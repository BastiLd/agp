RestoreInventory

A Fabric mod that automatically backs up your inventory and lets you restore it on demand — across deaths, mistakes and even mod updates.

Features

  • Auto (short), Auto (long), Manual and Death.

  • Choose how often the Auto slots save.

  • Saved into the dedicated Death slot.

  • The current inventory is saved first.

  • 9×6 view with armor, inventory, hotbar, off-hand.

  • Relative time, item count and best tool.

  • Right-click to prevent overwriting saves.

  • Configure how many saves each slot keeps.

  • Toggle the restore sound per player.

  • English and German included.

  • Runs off the server thread — no lag spikes.

  • Stored in restoreinv/<uuid>.

  • 1.21–1.21.1, 1.21.2–1.21.4, 1.21.9–1.21.11.

  • /restoreinv 1|2|3|4, save, undo, saves, config, version.

  • restoreinv.admin and restoreinv.restore (OP fallback).

  • Saves survive updates, backward-compatible.

Commands

Command Description
/restoreinv 1|2|3|4Restore from Auto-short / Auto-long / Manual / Death.
/restoreinv saveSave current inventory to the Manual slot.
/restoreinv undoUndo the last restoration.
/restoreinv savesOpen your save list GUI.
/restoreinv configOpen the configuration GUI (admins only).
/restoreinv versionShow the mod and Minecraft version.
Aliases /rinv, /restoreInv Shortcuts for /restoreinv.

Permissions

Node Effect
restoreinv.adminAccess config GUI, admin panel, restore other players.
restoreinv.restoreRestore your own inventory (/restoreinv and undo).
