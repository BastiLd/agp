# Self-hosting, Sync, ZimaOS, and Docker

## MVP decision

Do not build sync in the first prototype.
Build local-first file storage correctly first.

## Future self-hosting options

- Option A: Static web app only
- Option B: WebDAV support
- Option C: Git-based vault sync
- Option D: ObbyMM Sync Server

## Important rule

Do not design the app so it requires a central server.
The self-hosted server is an optional convenience, not the foundation.
