# ObbyMM Product Vision

## Name

**ObbyMM**

Working meaning:

- Obby = inspired by Obsidian-style local thinking workflows
- MM = Mindmaps

## One-line pitch

**ObbyMM is Obsidian for Mindmaps.**

## Product definition

ObbyMM is a local-first, offline-first, open-format thinking app where Markdown notes and visual mindmaps live together in a real vault folder.

It combines:

- Obsidian-style vaults
- Markdown notes
- `.canvas` mindmaps
- Wikilinks
- Backlinks
- Command palette
- Themes
- Event-history-based undo/redo
- Replay/timelapse of how a mindmap grew over time

## Why this should exist

Many mindmap apps are either:

- ugly
- expensive
- too limited in the free version
- cloud-first
- too business-focused
- bad on mobile
- not open enough
- missing a real thinking history

ObbyMM should feel like a clean local thinking workspace instead of a locked-in cloud app.

## Target users

Primary users:

- students
- pupils
- people who want to organize thoughts quickly
- self-learners
- people already attracted to Obsidian-like workflows

Secondary users later:

- writers
- researchers
- creators
- project planners
- personal knowledge management users

## Product principles

### 1. Local-first

The user owns their data. The app works without an account and without cloud.

### 2. File-first

Mindmaps and notes should be real files in a vault folder where possible.

### 3. Open formats

Use `.md` for notes and `.canvas` for mindmaps.

App-specific replay/history data belongs in sidecar files.

### 4. Simple at first, powerful later

The app must feel easy from the first minute, but it should be designed so advanced features can grow naturally.

### 5. Replay is a core identity feature

The app should not only show what the user thinks now. It should show how the thought process developed.

### 6. Free core forever

The important core features remain free.

Future paid features should be optional extras, not locked basics.

## Free core

The free core should include:

- local vaults
- Markdown notes
- mindmaps
- basic node types
- basic themes
- undo/redo
- basic replay
- basic search
- backlinks
- import/export basics

## Possible paid extras later

Optional one-time purchases, not subscriptions by default:

- AI tools
- premium theme packs
- advanced replay exports
- export templates
- advanced self-hosted sync helpers
- plugin marketplace extras

Important rule:

> Anything that was free before stays free.

## Brand feeling

ObbyMM should feel:

- calm
- fast
- clean
- dark-mode friendly
- Obsidian-like
- slightly creative
- not childish
- not enterprise-heavy
- reliable
