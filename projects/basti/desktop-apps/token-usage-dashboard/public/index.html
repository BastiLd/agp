Input
Neuer, nicht gecachter Text, den Claude liest (deine Nachricht, Tool-Ergebnisse).
Cache schreiben
Kontext, der beim ersten Mal in den Prompt-Cache gelegt wird.
Cache lesen
Schon gecachter Kontext, der bei jeder weiteren Nachricht erneut gelesen wird – darum so groß. Bei der API kostet das nur 10 % von normalem Input; wie stark es in dein Abo-Limit einfließt, veröffentlicht Anthropic nicht.
Output
Text, den Claude schreibt (inkl. Tool-Aufrufe und Thinking).
Thinking
Der „Nachdenk“-Anteil vom Output.

* Auslastung = Tokens im aktuellen Block im Vergleich zu dem Block, in dem du zuletzt ans 5-Std-Limit gestoßen bist (sonst: dein größter Block). Nur eine Schätzung – erfasst wird nur Claude Code, nicht claude.ai oder die App, und die exakte Limit-Formel ist nicht öffentlich.
